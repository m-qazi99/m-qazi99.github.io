Which project checks CSV quality?

DataLens checks a single dataset against explicit contracts and can compare distribution drift. Recon Lab compares source and target records using business keys. Use quality checks to ask whether records satisfy a rule; use reconciliation to ask whether two snapshots agree.

Does Runbook Radar use a generative AI model?

No. The public application retrieves source passages using BM25 or TF-IDF cosine similarity. It exposes matching terms and labeled retrieval evaluation. It does not call an LLM or generate operational instructions.

Can the browser apps run Python without a server?

The live apps load Pyodide and execute Python in a background browser worker. The first run needs an internet connection to download the runtime. The repositories also include native Python interfaces. Browser-local processing does not make a webpage suitable for confidential data by default; use the supplied synthetic examples when exploring.
