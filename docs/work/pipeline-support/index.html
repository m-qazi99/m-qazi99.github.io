01 / AI-assisted diagnostics

AI Data Pipeline Support Assistant

An assistant that interprets ADF execution traces and turns technical errors into diagnostic guidance and incident communication.

Project context

Résumé-based project summary
Updated October 2026

Tools & concepts

PythonStreamlitADFSQLLLM API

Workflow diagrams illustrate the documented approach, rather than a deployed system.

The problem

Pipeline failures leave engineers with execution traces, exceptions, and a time-sensitive investigation. Turning that information into a useful next step and a clear stakeholder update can involve repetitive work.

My contribution

Developed a troubleshooting utility to interpret Azure Data Factory execution traces and pipeline exceptions, produce diagnostic guidance, and draft validation SQL and incident communication.

Implementation

The résumé describes a Python and Streamlit utility using an LLM workflow with ADF error information and SQL validation context. Its outputs include likely failure context, troubleshooting steps, and structured communication.

Documented outcome

The documented result is a reusable diagnostic workflow that brings investigation and communication into one utility. No independently verified time savings or production deployment evidence is available, so no numerical performance claim is made here.

Scope & evidence

Diagnostic guidance and generated SQL require engineering review. The available project description does not document the model provider, hosting environment, evaluation dataset, or measured accuracy.

A useful next conversation

A useful next evidence step is a sanitized failure example, the assistant's response, and a record of which suggested checks were correct.
