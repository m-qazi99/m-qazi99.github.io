Privacy Forge — CSV privacy policy experimentation

Design a column-by-column transformation policy. Explore what stays useful, what remains exposed, and how small groups can reveal more than expected.

Privacy Forge is an independent Python project by Muzammil Qazi in the area of csv privacy policy experimentation.

Launch Privacy Forge ↗Source repository ↗

What does Privacy Forge do?

Design a column-by-column transformation policy. Explore what stays useful, what remains exposed, and how small groups can reveal more than expected.

  • Visual column policy builder
  • Six transformation actions
  • Quasi-identifier group exposure
  • Hashed input/output audit receipts

How does the Python implementation work?

Column policies for keeping, dropping, redacting, tokenizing, or generalizing cells; heuristic signals; exact quasi-identifier groups; hashed audit receipts.

The live browser application runs Python through Pyodide in a background worker. The repository includes a native Python CLI and a local HTTP API using the same engine.

Scope and limitations

Heuristic discovery and group-size analysis do not guarantee anonymization. Generalized values can still reveal identifying information.

The five public applications are independent portfolio projects developed with Codex assistance. They use synthetic demonstrations and do not establish employer deployment, client outcomes, certifications, or production adoption.
