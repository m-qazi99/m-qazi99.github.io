Recon Lab — Source-to-target CSV reconciliation

Move beyond row counts. Investigate field-level differences, model tolerance policies, and trace every exception to its source.

Recon Lab is an independent Python project by Muzammil Qazi in the area of source-to-target csv reconciliation.

Launch Recon Lab ↗Source repository ↗

What does Recon Lab do?

Move beyond row counts. Investigate field-level differences, model tolerance policies, and trace every exception to its source.

  • Selectable record diff inspector
  • Absolute and relative Decimal policies
  • Tolerance sensitivity frontier
  • Control totals and exception ledger

How does the Python implementation work?

Unique composite-key matching, Decimal arithmetic, absolute and source-relative tolerance, opt-in text normalization, control totals, and exception exports.

The live browser application runs Python through Pyodide in a background worker. The repository includes a native Python CLI and a local HTTP API using the same engine.

Evidence and reproducibility

  • Python engine source
  • Automated tests
  • Synthetic example inputs

Scope and limitations

No automatic data repair. Equal totals do not establish record equality; business keys and tolerance policies must be chosen deliberately.

The five public applications are independent portfolio projects developed with Codex assistance. They use synthetic demonstrations and do not establish employer deployment, client outcomes, certifications, or production adoption.
