DataLens is an independent Python project by Muzammil Qazi in the area of csv data quality and distribution drift.

Launch DataLens ↗Source repository ↗

What does DataLens do?

Turn a dataset into a living quality map. Write contracts, find the exact failures, and compare distribution shifts against a baseline.

  • Row-level quality heatmap
  • Executable JSON contracts
  • Baseline PSI drift comparison
  • Distribution and schema inspection
  • Review Desk handoff exports

How does the Python implementation work?

Not-null, uniqueness, numeric, range, and allowed-value contracts; record-level violations; smoothed Population Stability Index comparisons.

The live browser application runs Python through Pyodide in a background worker. The repository includes a native Python CLI and a local HTTP API using the same engine.

Scope and limitations

Contract scores are rule pass rates, not dataset accuracy. PSI thresholds are review heuristics, especially with small samples.

The five public applications are independent portfolio projects developed with Codex assistance. They use synthetic demonstrations and do not establish employer deployment, client outcomes, certifications, or production adoption.
