What does Pipeline Pulse do?

Build your own pipeline, solve graded incident challenges, and compare worker capacity against a completion target. Save named experiments and return to your investigations.

  • Visual DAG builder
  • Python-graded incident challenges
  • Capacity planning frontier
  • Local experiment vault
  • Review Desk handoff exports

How does the Python implementation work?

Discrete-event DAG scheduling; dependency validation; bounded retries; critical-path lower bound; worker-capacity comparisons; Python-graded incident scenarios.

The live browser application runs Python through Pyodide in a background worker. The repository includes a native Python CLI and a local HTTP API using the same engine.
