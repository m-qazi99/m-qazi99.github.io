05 / A little context

An operational eye.

mq.

I'm Muzammil, an Azure data engineer based in Pune. My experience at Cognizant connects enterprise operations with data engineering: understanding what a workflow needs to do, investigating where it breaks, and making the next handoff clearer.

My work spans ingestion with Azure Data Factory, transformations with Databricks and PySpark, and SQL-based validation and reconciliation. I'm especially interested in the practical layer around a pipeline: useful telemetry, understandable errors, and documentation people can actually use.

I'm applying AI to that same set of problems through diagnostic assistants, metadata-driven SQL generation, and retrieval over operational documents. My direction is simple: reliable data foundations, with automation that helps people make better decisions.
