## Brand and interaction choices

- **Positioning:** Azure Data Engineer · AI Workflow Automation · Intelligent Data Operations. Based on the existing user-owned profile content, not the reference developers' credentials.
- **Visual identity:** midnight navy, translucent glass panels, mint highlights, quiet lavender/blue accents, and an original mq. orbital monogram.
- **Website:** searchable technology atlas, category filters, selectable synthetic pipeline scenarios, dedicated About and Contact routes, project case studies, and a mailto brief builder.
- **GitHub:** original light/dark SVG header, capability table, expandable technology atlas, direct interactive website links, and explicit project scope.
- **Accessibility:** semantic landmarks, keyboard-operable controls, visible focus, text labels, responsive grids, reduced-motion support, and status announcements for changing results.
- **Evidence:** no invented clients, certifications, testimonials, project metrics, coding statistics, or proficiency percentages. Learning areas remain identified.

## Platform constraints

GitHub sanitizes README HTML and does not run embedded JavaScript or custom site CSS. Its interactions use links and native details/summary. Search, filters, and scenario changes live on the website. Contact prepares an email locally; it does not submit or store a message.
